# Repository completeness audit

Tracked source is substantial: 12,581 Git paths and 8,949 PHP paths across both roots, including public entries, skins, libraries, payment integration source, LMS, JavaScript, CSS, and branded static assets. `git status --short` was clean at audit start.

The `.gitignore` deliberately excludes `html{,2}/data/*` except structural controls, DB dumps, credentials/`dbconfig.php`, provider private config/key material, runtime cache/session/log/tmp/upload paths, and common export formats. This is appropriate for secrets and runtime/PII, but prevents exact reconstruction of data-driven production pages until read-only data/config discovery occurs.

No source-level broken include inventory was generated by executing PHP because boot requires the intentionally absent DB bootstrap. Static source existence is generally adequate; runtime include/plugin activation remains configuration-dependent.
