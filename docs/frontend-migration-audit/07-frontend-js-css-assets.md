# Frontend JS, CSS, and assets

Shared head loads jQuery 1.12.4, GnuBoard JS, branded `menu.js`, Owl Carousel, GSAP/TweenMax, Jarallax, LightSlider, AOS, Swiper 7, lightbox, local CSS under `src/nonsul-learn/css/`, skin CSS, fonts/icons and external Google/CDN resources. The home uses Swiper hero autoplay (5s), Owl carousels, and GSAP quick-link expansion. Teacher cards use IntersectionObserver-style scroll reveal inline.

All branded image/font assets located under `html/src/nonsul-learn/` are tracked. Runtime banner and board upload files under `data/` are intentionally absent. Rebuild interactions as accessible React components; preserve timing and controls only where observable parity matters, and replace legacy libraries where visual testing proves parity.
