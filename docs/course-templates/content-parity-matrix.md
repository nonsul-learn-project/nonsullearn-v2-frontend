## 3. 세 템플릿의 블록 구조 차이

공통 컴포넌트와 유형별 컴포넌트를 가르는 기준이다.

| 블록 | 인문 | 수리 | 약술 | 공용화 |
|---|---|---|---|---|
| 00 고정 바 | 투명→다크 | 투명→아이보리 | 항상 화이트 + `논술런` 워드마크 | **가능** (토큰 + 워드마크 옵션) |
| 01 히어로 | 좌측 700px 1열, `{heroMark}` **배경 블록** 강조 | H1 전체 폭 + 하단 7:5 | 좌측 H1 + 우측 정보(2px 좌측선) | **불가** — 레이아웃 3종 |
| 02 문제 공감 | **4카드** auto-fit, 02와 수강전후 통합 | **3개 번호 행** (카드 금지 명시), 02-A/B 분리 | **4항목 2×2 격자** 구분선, 02-A/B 분리 | **불가** |
| 02-B 수강 전·후 | 3행 flex | 3행 (상단 1px 실선) | 머리행 2px + 3행 | **가능** (토큰 차이만) |
| 03 신뢰 근거 | `BrandStats` **항상** + 사례 조건부 | `brandStats` **조건부** + 사례 조건부 | `VerifiedStats` 조건부 (**범위 칩 없음**) | **가능** (props로 흡수) |
| 03 합격증 띠 | 동일 명세 | 동일 명세 | 동일 명세 | **가능 — 완전 동일** |
| 04 수업 루프 | 3**카드** (패딩 32px) | 3열 목록, 상단 2px 선 (02만 바이올렛) | 3단계 가로 + **에메랄드 화살표** | **불가** |
| 04 강사 | 사진 4:5 + 이력 3행 (소개 문장 **없음**) | 사진 + **소개 1~2문장** + 이력 3행 | 사진 + 소개 + 이력 3행 + H3 `강사 소개` | **가능** (소개 optional) |
| 05 커리큘럼 | 번호 96px + 라벨 + 제목 + 설명 + 메타 (**시간 없음**) | 번호 72px + ... + **오른쪽 강의 시간** | 번호 80px + ... + **오른쪽 강의 시간** | **가능** (duration optional) |
| 06 매회 구성 | 시간 비율 가변 막대 56px | 가변 막대 56px | **3칸 고정** flex 1:2:1, 64px | **가능** (막대 모드 2종) |
| 06 첨삭 | 2단계 카드 | 2단계 카드 | 2단계 + 민트 `→` | **가능** |
| 07-A 추천 | **번호** 01~04 | 번호 01~04 | **체크 아이콘** | **가능** (마커 옵션) |
| 07-A 정보 카드 | 라벨+값+**보조줄** | 라벨+값+보조 | 라벨+값 (**보조줄 없음**) | **가능** |
| 07-B 탭 | 하단 2px accent 내부 그림자 | 선형 탭 | 하단 2px 포레스트 | **가능** |
| 07-C 신청 | 중앙 H2 + `{closing}` + 패널 640px | H2 + 패널 (flex 5, **요약 문장 없음**) | 중앙 H2 + `{closing}` + 패널 680px | **가능** (closing optional) |
| 07-D FAQ | 800px `<details>` | 800px | 800px | **가능 — 거의 동일** |

**결론**: 01 히어로 / 02-A 문제 공감 / 04 수업 루프 3블록만 유형별 전용이고,
나머지 11블록은 공용 컴포넌트 + 테마 토큰 + props로 커버된다.

## 4. 신규 카피 vs 기존 강좌 정보 충돌

| 충돌 | 내용 | 해소 방안 |
|---|---|---|
| C-1 | 히어로 `<h1>`이 강좌명(기존) ↔ 마케팅 헤드라인(신규) | 결정 D2. 같은 유형 강좌가 모두 동일 `<h1>`이 되면 SEO 저하 |
| C-2 | `promise` "합격을 약속하지 않습니다" ↔ `headHtml`/`descriptionHtml`에 기존 홍보 문구가 있을 수 있음 | 결정 D3에서 함께 판단. 모순 문구 공존 금지 |
| C-3 | 정가 취소선: Legacy는 `listPrice`가 0이어도 표시 ↔ 템플릿은 "없거나 판매가와 같으면 숨김" | G-05. 템플릿 규칙 채택 권장 (표시 오류 교정) |
| C-4 | `수강기간`: Legacy `수강 시작 후 N일` ↔ 템플릿 예시 `시작 후 90일` | 기존 문구 유지. `extra[2]`가 숫자(일)이므로 조립 규칙 보존 |
| C-5 | 템플릿 `coming_soon` 상태 ↔ 데이터에 해당 개념 없음 | G-06. 사용하지 않는다 |
| C-6 | 03 블록 브랜드 수치 ↔ 강좌별 실적으로 오해 | copy.md가 이미 `연구소·브랜드 전체 기준` 칩과 주석을 규정. 그대로 따른다. 단 수치 자체가 미검증 → 기본 off |
