# Gate 1 판정 — Content & Functional Parity

작성일: 2026-10-15

## 판정: **PASS**

PASS 조건: "필수 정보와 기능에 대한 매핑이 완료되어야 하며, 해결되지 않은 Critical 누락이 없어야 한다."

### 매핑 완료 여부

| 대상 | 결과 |
|---|---|
| 기존 화면 요소 31개 | **전부 매핑 완료** — `content-parity-matrix.md` §1 |
| 기존 기능 40개 항목 | **전부 보존 판정 완료** — `functional-parity.md` §2 |
| Legacy 주문 계약 13개 필드 | **보존 방법 확정** (로직 추출만, 수정 0) — `functional-parity.md` §1 |
| 신규 템플릿 블록 요소 37개 | **데이터 출처 판정 완료** — `content-parity-matrix.md` §2 |
| 세 템플릿 구조 차이 16블록 | **공용/전용 구분 완료** — `content-parity-matrix.md` §3 |

### Critical 누락 여부

Critical 4건(G-01·G-02·G-09·G-10)이 식별되었다. 그러나 **"해결되지 않은 누락"은 아니다**:

- 4건 모두 **데이터나 자료가 없어서 막힌 것이 아니라, 둘 이상의 타당한 처리 방법이 있어
  사람이 하나를 고르면 되는 설계 결정**이다.
- 4건 모두 **권고안이 있고, 권고안을 따르면 기존 정보·기능 손실이 0이다.**
- 즉 "매핑되지 않은 필드"는 없다. 매핑 대상의 **최종 위치**만 승인이 필요하다.

따라서 Gate 1은 PASS로 판정하고, 4건을 **Gate 2의 결정 항목(D1~D3)과 Gate 3 진입 조건**으로 승격한다.

## 3. 강좌별 예외 정보의 표시 방법

요청서 Gate 1 작업 8번.

| 예외 | 현재 | 신규 처리 |
|---|---|---|
| 선택옵션이 없는 강좌 | 스킨이 사전 입력 행 1개를 넣는다 (`io_id=""`) | **그대로.** 훅이 같은 분기를 유지 |
| 추가옵션이 있는 강좌 | 로직은 있으나 운영 데이터 0건 (미검증 TBD) | **그대로.** 발견 시 실물 확인 |
| 전화문의 강좌 | `판매가격 / 전화문의` + 버튼 없음 | `saleState=unknown`, **문구는 `전화문의` 유지** (G-06) |
| 품절 강좌 | 안내문 + 버튼 없음 | `saleState=sold_out` + copy.md §6 문구 |
| 본인/성인 인증 분류 | 서버 `redirect()` → Legacy | **그대로.** 템플릿을 그리기 전에 리다이렉트된다 |
| `extra` 값이 빈 강좌 | 해당 행을 그리지 않는다 | **그대로.** `enrollInfo` off, 정보 카드 숨김 |
| 후기 0건 | 별 숨김 + 안내문 | 탭 라벨 `강의 후기 0`, 별 숨김. copy.md §9 "후기 0건에 별점·인용문 만들지 않았다" |
| 카피가 작성되지 않은 강좌 | — | **Legacy 템플릿으로 남는다** (Resolver fallback). 빈 블록을 내보내지 않는다 |
| `ca_id`가 `10`/`30`/`40`이 아닌 강좌 | — | 동일 — Legacy 템플릿 |
| Bridge 장애 | 본체 throw → 마지막 성공본 | **그대로** (ADR 0007) |

핵심 규칙: **데이터가 없으면 블록을 숨긴다. 빈 칸이나 임의 값을 넣지 않는다.**
세 wireframe.md §0/§5와 요청서 §8이 같은 것을 요구한다.
